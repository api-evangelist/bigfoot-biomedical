# Bigfoot Biomedical

> Bigfoot Biomedical was a Milpitas, California medical-device company building connected insulin-management technology for people with insulin-requiring diabetes. Its FDA-cleared Bigfoot Unity Diabetes Management System paired reusable smart insulin pen caps with Abbott FreeStyle Libre 2 iCGM data and a clinician-set dosing program, showing real-time glucose values, trends and recommended correction doses on the pen cap itself. Abbott announced the acquisition of Bigfoot on 5 September 2023 and closed it the same month. The company is now fully absorbed into Abbott; bigfootbiomedical.com is an Abbott-hosted archive headed "Bigfoot is Now Abbott."

**Bigfoot Biomedical has no public API.** There is no developer portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no CLI, no webhook catalog, no MCP server and no A2A agent card on any Bigfoot-owned host.
